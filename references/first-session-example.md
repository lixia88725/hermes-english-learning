# 首次使用评估示例

> 本文件为参考案例，展示一个真实首次会话的观察数据和评估方法。非规范性文档。

## 会话特征

- **触发方式**：用户说 "Oh, let's talk in English"（非正式触发，但意图明确）
- **会话长度**：~20 轮英文对话
- **语言模式**：全英（用户始终用英文，未切回中文）

## 词汇查询记录

用户主动问了以下词的含义（全部为中级词汇）：

| 词汇 | 级别 | 备注 |
|------|------|------|
| fires (verb) | 中级 | 技术隐喻用法，非字面义 |
| jargon | 中高级 | 第一次被解释后，后面主动用对了 |
| adaptation | 中级 | 用户自己给出中文释义"适应" |
| wrap up | 中级 | 短语动词 |
| per (formal) | 中级 | 用户已知"每一个"义项，不知"根据"义项 |
| locked in | 中高级 | 习语 |

## 语法观察

| 模式 | 错误示例 | 正确版本 | 纠正方式 |
|------|---------|---------|---------|
| 疑问句结构 | "what is X mean?" | "what does X mean?" | 自然重述 + 一次显式指出 |
| 动名词主语 | "Restate things correctly is OK" | "Restating things correctly is OK" | 自然重述 |
| 反义疑问句 | "doesn't" 应为 "does it" | — | 用户自我纠正 |
| 不可数/集合名词 | "any things" | "anything" | 自然重述 |

## 水平评估

- **CEFR**：B1（低中级）
- **词汇量估算**：3000-4000
- **判断依据**：
  - 能就日常话题进行流畅对话
  - 偶尔出现基础语法错误（疑问句结构、动名词）
  - 会自我纠正（B1→B2 过渡标志）
  - 问的词多为中级，未出现高级词汇查询
  - 听到正确版本后能主动复用（"what does X mean"从纠正到自动化仅用 3 轮）

## 观察要点

1. **"what does X mean"模式是良好的探测信号**：用户掌握此句式后，词汇学习效率大幅提升。
2. **首次会话不要评价得太早**：等足够数据（至少 10+ 轮有意义对话）后再做评估，避免基于过少样本误判。
