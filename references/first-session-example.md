# 首次使用评估示例

> 本文件为参考案例，展示记忆模型下首次英语陪读的观察和记录方式。

## 会话特征

- **触发方式**：用户说 "Oh, let's talk in English"（非正式触发，意图明确）
- **会话长度**：~20 轮英文对话
- **语言模式**：全英（用户始终用英文，未切回中文）

## 词汇观察

用户主动询问了以下词的含义：

| 词汇 | 是否常用 | 备注 |
|------|---------|------|
| fires (verb) | 常用 | 技术隐喻用法，非字面义，值得记录 |
| jargon | 常用 | 第一次被解释后，主动用对了 |
| wrap up | 常用 | 短语动词，常见度中高 |
| locked in | 中高频 | 习语，工作对话常用 |
| look up | 常用 | 短语动词，高频 |
| per (formal) | 常用 | 用户已知"每一个"，不知"根据"，补充义项 |
| poplar fluff | 生僻 | 临时好奇心，日常极少出现——优先淘汰 |

## 语法观察

| 模式 | 错误示例 | 正确版本 |
|------|---------|---------|
| 疑问句结构 | "what is X mean?" | "what does X mean?" |
| 动名词作主语 | "Restate things correctly is OK" | "Restating things correctly is OK" |
| 反义疑问句 | "doesn't" 应为 "does it" | —（用户自我纠正） |
| 不可数/集合名词 | "any things" | "anything" |

## 水平评估

- **CEFR**：B1（低中级）
- **词汇量估算**：3000-4000
- **判断依据**：
  - 能就日常话题进行流畅对话
  - 偶尔出现基础语法错误（疑问句结构、动名词）
  - 会自我纠正（B1→B2 过渡标志）
  - 问的词多为中级，未出现高级词汇查询
  - 听到正确版本后能主动复用

## 首次会话后的 user_level.md

首次会话积累 10+ 轮有意义对话后，AI 应生成初始档案。示例：

```markdown
---
estimated_cefr: B1
estimated_vocabulary: 3000-4000
last_updated: 2026-05-17
---

# 英语水平档案

## 水平概述
B1 低中级，词汇量 3000-4000。日常话题流畅，句子偏短。
短板：疑问句结构（what does X mean 刚掌握）、动名词作主语、
短语动词积累不足。学习习惯好——主动追问，被纠正后即时复用。

## 近期词汇
- fires
- jargon
- wrap up
- locked in
- look up
- per

## 语法问题记录
- 动名词作主语："Restate things correctly" → "Restating things correctly"
- 反意疑问句：有回避倾向，用 right? 替代
- 主谓一致：集合名词后动词形式偶有偏差
```

## 观察要点

1. **「what does X mean」是良好的探测信号**——用户掌握此句式后，词汇学习效率大幅提升。
2. **首次会话不要评价得太早**：等足够数据（10+ 轮有意义对话）后再做评估。
3. **生僻词不入表或优先淘汰**：`poplar fluff` 是临时好奇心，日常极少出现，无需占用窗口空间。
4. **语法条目按出现频率排序**：动名词作主语出现 3 次排第一，反意疑问句 1 次排最后。
