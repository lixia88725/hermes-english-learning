# Hermes 英语陪练

一个基于 AI 的英语对话陪练 Skill，专为 [Hermes Agent](https://hermes-agent.nousresearch.com) 设计。

[English version →](README.md)

## 功能概述

把 Hermes 变成一个耐心、地道的英语陪练伙伴。通过自然重述（而非说教）纠正语法、追踪词汇增长、根据你的 CEFR 水平动态调整对话难度（i+1 原则）。

## 核心特性

- **自然纠错** — 在对话中通过示范正确说法来纠错，不打断对话节奏
- **词汇追踪** — 追踪学习中的词汇，记录从「初接触」到「已掌握」的完整过程
- **自适应难度** — 句子复杂度始终略高于你当前水平，每次最多引入 1-2 个可从上下文推断的生词
- **语音合成** — 所有英文回复自带语音（Edge TTS），支持语速调节
- **语法盲区检测** — 识别反复出现的语法错误模式，在对话中无感强化

## 安装配置

1. 将本 Skill 复制到 `~/.hermes/skills/creative/english-learning/`
2. 创建你自己的学习档案 `user_level.md`（模板见下方）
3. 确保 Edge TTS 已在 Hermes 配置中启用

## `user_level.md` 学习档案模板

```yaml
---
estimated_cefr: ""    # 留空即可，约 10 轮对话后自动评估
estimated_vocabulary: ""
last_updated: ""
---

# 英语水平档案

## 词汇追踪

|------|------|---------|---------|

## 语法盲区

|--------|------|---------|---------|---------|
|        |      |         |         |         |
```

## 使用方式

说 **「英语模式」** 或 **「English mode」** 激活，说 **「退出英语模式」** 退出。剩下的交给 Skill。
